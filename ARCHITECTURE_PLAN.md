# Архитектура мультистранового интернет-магазина (Украина/Франция)

## 📋 Анализ текущей реализации

### Что уже реализовано:

1. **Роутинг по странам**
   - Middleware автоматически определяет страну из URL (`/[countryCode]`) или IP (Vercel)
   - Поддержка множественных регионов через Medusa
   - Автоматический редирект на соответствующий country code

2. **Локализация интерфейса**
   - Поддержка локалей через Medusa backend (`/store/locales`)
   - Locale хранится в cookie (`_medusa_locale`)
   - Передача locale через header `x-medusa-locale` в API запросах
   - UI компонент для переключения языка

3. **Регионы и цены**
   - Регионы привязаны к странам (country codes)
   - Корзина привязана к `region_id`
   - Цены рассчитываются по региону
   - Автоматическое обновление корзины при смене региона

4. **Структура данных**
   - Продукты фильтруются по `region_id`
   - Категории и коллекции поддерживают локализацию через Medusa
   - SEO-friendly URLs с country code

### Что нужно доработать:

1. **Локализация контента товаров**
   - Названия, описания, метаданные
   - Категории и коллекции
   - SEO метатеги

2. **Локализация UI текстов**
   - Статические тексты интерфейса (кнопки, формы, сообщения)
   - Сообщения об ошибках
   - Email шаблоны (если используются)

3. **Специфичные настройки по странам**
   - Валюты (UAH для Украины, EUR для Франции)
   - Способы доставки
   - Способы оплаты
   - Налоги (VAT для Франции, возможно для Украины)

4. **SEO оптимизация**
   - Hreflang теги
   - Локализованные метатеги
   - Структурированные данные (Schema.org)

## 🏗️ Предлагаемые варианты архитектуры

### Вариант 1: Полная локализация через Medusa (Рекомендуется)

**Принцип:** Вся локализация контента управляется через Medusa backend, frontend только отображает.

**Преимущества:**
- ✅ Единый источник правды (Medusa)
- ✅ Легко управлять контентом через админку
- ✅ Автоматическая синхронизация
- ✅ Поддержка множества языков без изменений в коде

**Недостатки:**
- ⚠️ Зависимость от возможностей Medusa по локализации
- ⚠️ Может потребоваться настройка в Medusa admin

**Реализация:**
- Использовать встроенную локализацию Medusa для продуктов/категорий
- Locale передается через `x-medusa-locale` header (уже реализовано)
- UI тексты через i18n библиотеку (next-intl или react-i18next)

**Структура:**
```
/[countryCode]/[locale]/...
  - ua/uk/... (Украина, украинский)
  - ua/ru/... (Украина, русский - опционально)
  - fr/fr/... (Франция, французский)
  - fr/en/... (Франция, английский - опционально)
```

## 🎯 Финальная архитектура (Гибридный подход)

### Структура роутинга

```
/[countryCode]/
  ├── ua/             # Украина (locale из cookie/header)
  │   ├── products/
  │   ├── cart/
  │   └── checkout/
  └── fr/             # Франция (locale из cookie/header)
      ├── products/
      ├── cart/
      └── checkout/
```

**Локали определяются:**
- Из cookie `_medusa_locale` (приоритет)
- Из `Accept-Language` header (fallback)
- По умолчанию: `uk` для UA, `fr` для FR

### Компоненты архитектуры

#### 1. **Роутинг и Middleware**
```typescript
// middleware.ts
- Определяет country code из URL
- Определяет locale из cookie или Accept-Language header
- Устанавливает cookies для country и locale
- Редиректит на правильный URL если нужно
```

#### 2. **Локализация контента товаров**
```typescript
// Через Medusa API
- Запросы с header: x-medusa-locale
- Medusa возвращает локализованный контент
- Fallback на default locale если перевод отсутствует
```

#### 3. **Локализация UI**
```typescript
// Используя next-intl
- Файлы переводов: /messages/uk.json, /messages/fr.json
- Компоненты используют useTranslations()
- Поддержка форматирования дат, чисел, валют
```

#### 4. **Регионы и валюты**
```typescript
// В Medusa Admin настроить:
- Region "Ukraine" (UA) 
  -> Currency: UAH
  -> Countries: UA
  -> Shipping Providers: Новая почта, Укр почта
  -> Payment Providers: Stripe (карта), Manual (наложенный платеж)
  
- Region "France" (FR)
  -> Currency: EUR
  -> Countries: FR
  -> Shipping Providers: La Post, Colissimo
  -> Payment Providers: Stripe (карта), Manual (наложенный платеж)
```

#### 4.1. **Локали в Medusa**
```typescript
// Настроить в Medusa Admin:
- uk (украинский)
- ru (русский)
- fr (французский)
- en (английский) - fallback
```

#### 5. **SEO оптимизация**
```typescript
// В каждом layout/page
- Hreflang теги для всех комбинаций country/locale
- Локализованные метатеги (title, description, OG)
- Структурированные данные (Product, BreadcrumbList)
- Локализованные URLs
```

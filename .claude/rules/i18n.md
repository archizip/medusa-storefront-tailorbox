# Locale files

There are four locales and they must stay in sync: `en`, `fr`, `ru`, `uk`.

Adding a key to one file means adding it to **all four** `messages/*.json`. A key present in
`en.json` but missing elsewhere renders as the raw key to those users.

Keep the key structure identical across files — mirror the nesting, don't flatten one and nest
another.

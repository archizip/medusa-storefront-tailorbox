Доставь фичу: **$ARGUMENTS**

Действуй как полноценный разработчик и следуй циклу из `CLAUDE.md` (раздел 4):

1. **Понять** — найди и прочитай релевантные модули в `src/modules` и функции слоя данных
   в `src/lib/data`. Сверься с паттернами Medusa v2 (MCP `query-docs` или docs.medusajs.com),
   если задействуется незнакомый API.
2. **Спланировать** — определи: какой модуль/страница, какие функции `lib/data` нужны
   (новые или существующие), какие ключи переводов. Меняй минимально необходимое.
3. **Реализовать**:
   - UI → `src/modules/<домен>/components|templates`, страница → `app/[countryCode]/(main)/...`
   - Данные → только через `src/lib/data/*` (никаких прямых вызовов SDK из компонентов)
   - Server Components по умолчанию; `"use client"` только при необходимости (MUI — в client)
   - Все строки → во все 4 локали `messages/{en,fr,ru,uk}.json`
   - Алиасы `@lib @modules @components`; деньги — через `lib/util/money.ts`
   - Добавь loading-состояния для новых роутов
4. **Проверить (gate):** `yarn typecheck` и `yarn lint` должны пройти чисто. Для UI —
   допиши E2E в `e2e/` и прогони `yarn test:e2e`, либо проверь вручную через `yarn dev`.
5. **Самопроверка** diff: нет мусора/console.log/хардкода строк/обхода `lib/data`.
6. **Отчёт:** что сделано, что проверено (с выводом команд), что осталось.

Не коммить без явной просьбы. На ветке по умолчанию — сначала создай ветку.

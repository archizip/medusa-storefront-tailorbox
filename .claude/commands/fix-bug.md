Почини баг: **$ARGUMENTS**

Следуй дисциплине починки багов из `CLAUDE.md`:

1. **Воспроизведи** сначала. Определи точный сценарий. По возможности напиши падающий
   E2E-тест в `e2e/`, который демонстрирует баг, ИЛИ опиши ручные шаги воспроизведения.
2. **Найди корневую причину.** Прочитай задействованный модуль и соответствующие функции
   `src/lib/data`. Не лечи симптом — найди источник.
3. **Почини минимальным дифом.** Не рефактори лишнее, придерживайся стиля окружения.
4. **Докажи фикс:**
   - `yarn typecheck` и `yarn lint` — чисто
   - регресс-тест, который падал, теперь проходит (`yarn test:e2e`), либо ручная проверка
     через `yarn dev` показывает исправленное поведение
5. **Отчёт:** корневая причина, что изменено, как проверено (с выводом). Если баг
   зависит от данных недоступного backend — отметь это явно.

Не коммить без явной просьбы.
